## 📊 English

### Overview
This project analyzes **temperature anomaly data** in Iran from 1961 to 2020.  
Temperature anomaly means the difference from the long-term average (baseline).  
Positive values = warmer than average | Negative values = colder than average.

### Dataset
- **Source:** FAO (Food and Agriculture Organization of the United Nations)
- **File:** `FAO_STAT_iran_change_temp.csv`
- **Time Period:** 1961 - 2020 (Monthly data)

### Key Questions
1. Has Iran experienced global warming in the past 60 years?
2. Which years were the hottest and coldest?
3. How has temperature volatility changed over decades?

### Tools Used
- `pandas` - Data cleaning and analysis
- `matplotlib` - Visualization
- `numpy` - Statistical calculations
- `Jupyter Notebook` - Interactive development

### Project Structure

### How to Run
1. Clone this repository
2. Install requirements: `pip install pandas matplotlib numpy jupyter`
3. Run Jupyter: `jupyter notebook`
4. Open `notebooks/01_temperature_analysis.ipynb`
